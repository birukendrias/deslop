# deslop

Paste AI-sounding text. Get a plainer draft.

Client-side rules only for v0.1: banned words, em-dash cleanup, “not X but Y” softening, emoji strip. No account. No upload to a server.

## Run

```bash
npx --yes serve . -l 5174
```

Open http://localhost:5174

## Deploy

Static site. Point Vercel/Netlify at this folder.
